# PromocionAlVoto

El código Angular local incluye la integración de los cambios recuperados de Firebase Hosting y Cloud Functions. Para trabajar con la versión editable, ejecuta `npm start` y abre http://localhost:4200.

La aplicación local se conecta al proyecto Firebase real `promocion-al-voto`. La copia publicada original se conserva en `recovery/firebase-live` y puede consultarse con `npm run start:recuperado` en http://127.0.0.1:4300. El respaldo del código anterior y los detalles de integración están en [recovery/README.md](recovery/README.md).

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 22.0.0.

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
